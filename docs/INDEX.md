## 快速上手

```bash
pnpm install
pnpm dev                      # 终端形态启动内核（7 个 builtin 插件）
pnpm start                    # Electron 桌面应用（renderer 是 Svelte 5）
pnpm test:run                 # 全量测试（43 文件 / 355 用例）
pnpm typecheck:all            # 三份 tsconfig 类型检查
```

## 边界由契约测试把关

`tests/contract/` 5 个文件、35 个用例，静态断言：

| 断言                                          | 保障什么                     |
| --------------------------------------------- | ---------------------------- |
| 内核与 host 零第三方 import、不得反向 import  | `01` §1 的分层硬约束         |
| `dependencies` 恒为 `{}`                      | 内核零依赖红线               |
| 插件只从 `rem2-kernel` 导入、`entry` 是 `.js` | `02` 的导入与产物边界        |
| `src/shared` 零 import、方法/事件键集合相等   | `03` §3 的白名单不会漂移     |
| 扩展点清单与 `EXPECTED_IDS` 一致              | `01` §4.1 的扩展点表不会漂移 |
| renderer 产物是浏览器版 svelte                | 不会白屏                     |
